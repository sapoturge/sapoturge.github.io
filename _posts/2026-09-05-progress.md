## Website updates

Apparently, Github is transitioning from the `github-pages` gem to plain jekyll via workflows.

from version 232 to version 15 because that is the last one that didn't say it wasn't compatible
with Ruby 4. This means a lot of things broke, and it has been difficult to preview these posts
locally.

I got it to work last week, and got it to work differently this week, but I need to migrate properly
so I can keep it running in the future. I found a blog post describing the process, so it shouldn't
